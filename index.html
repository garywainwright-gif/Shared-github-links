One-time GitHub setup

  1. Create a public GitHub repository. A good name is shared-github-links.
  2. Upload the files from this folder, including index.html and links.json.
  3. Go to Settings → Pages → Deploy from branch → main → / (root) → Save.
  4. Share https://YOUR_USERNAME.github.io/shared-github-links/.
  5. To add or change links later, edit links.json in that repository.
